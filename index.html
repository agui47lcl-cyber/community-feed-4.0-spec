交互说明

  • 点击用户自己的头像进入「我的主页」
  • 点击关注数或粉丝数 → 进入对应二级页面
  • 点击动态 → 进入动态详情

  • 「喜欢」列表展示已点赞样式，支持取消点赞

5关注与粉丝

两个二级列表页：关注列表与粉丝列表，行为规则如下。

关注列表

  • 展示当前用户关注的其他人，合并用户端和代理端产生的关注关系
  • 支持取消关注，取消前需二次确认

粉丝列表

  • 展示关注当前用户的人
  • 支持关注对方

通用规则

  • 用户不允许关注自己
  • 点击他人头像 → 进入他人主页；点击自己的头像 → 进入「我的主页」

状态流转

启用中 —停用（二次确认）→ 已停用
状态变更结果
停用身份关联的全部上架动态下架，变更为「直播间下架」，且不能再上架；用户端不再展示该身份，关注列表和粉丝列表中也不再展示
重新启用身份恢复身份展示，但不会自动重新上架历史动态
  • 启用和停用均需二次确认
  • 使用已停用身份重新上架动态时，提示「当前发布身份已停用，请更改发布身份后重新上架」
停用发布身份

2我的主页（代理端）

结构与用户端「我的主页」一致：头像昵称、三项数据、动态 / 喜欢双页签。

页面内容

  • 展示头像、昵称、关注数、粉丝数和获赞数
  • 页面包含「动态」和「喜欢」两个页签
  • 点击关注数或粉丝数进入对应二级页面

业务规则

  • 获赞数 = 该用户动态获得的点赞总数
  • 「动态」仅包含已上架动态，按首次上架时间排序
  • 「动态」聚合代理端发布 + 用户端发布的已上架内容
  • 支持点赞和取消点赞
  • 点击动态进入详情；自己的动态详情不展示关注按钮
  • 「喜欢」仅展示点赞过且仍处于上架状态的动态，支持取消点赞

3关注与粉丝（代理端）

规则与用户端一致，关注关系同样合并两端产生。

关注列表

  • 展示当前用户关注的其他人，合并用户端和代理端的关注关系
  • 支持取消关注，取消前需二次确认

粉丝列表

  • 展示关注当前用户的人，并支持关注对方

通用规则

  • 不允许关注自己
  • 点击他人头像进入他人主页；点击自己的头像进入「我的主页」
